# 项目方案 · Stratus EPM（层云）

## 1. 创意定位

**名字**：Stratus（层云）  
**中文**：层云财务管控  

**隐喻**：集团合并像气象学中的层云——数据从各主体「蒸发」上升，在规则层「凝结」为调整与抵消，最终「降水」为可审计的合并报表与管理洞察。

**一句话**：  
> 把复杂的集团财务，变成可配置、可追溯、可协作的开源工作台。

**设计原则（创意内核）**

| 原则 | 含义 |
|------|------|
| **层云流水线 Cloud Pipeline** | 合并不是黑盒按钮，而是可视化阶段：采集→映射→调整→折算→抵消→汇总 |
| **规则即配置 Rules as Config** | 抵消/分摊/映射可版本化，财务用户可理解 |
| **驱动即预算 Drivers First** | 预算从业务量/人数出发，自动长出财务表 |
| **同源同层 One Source Many Layers** | 一次接入，法定合并/管理合并/预算/分析共用主数据 |
| **开源可信 Open by Default** | Apache-2.0，引擎可单测、可审计、可自部署 |

## 2. 目标用户

- 集团财务部 / 合并报表岗 / 管理会计
- 需要多组织、多币种、内部交易处理的成长型集团
- 希望用开源可控方案替代 Excel 合并或昂贵商业 EPM 的团队
- 高校与培训机构（合并会计教学沙箱）

## 3. 产品功能地图

### 3.1 M1 合并报表与附注

- 组织架构树 + 法定/管理多架构
- 持股比例与合并方法（全额/比例/权益法）
- 科目映射、多准则扩展点
- 多币种折算（期末/平均汇率）
- 内部往来与内部交易抵消（Trading Partner）
- 调整分录（审计/重分类）
- 合并快照、试算平衡校验、阶段明细追溯

### 3.2 M2 全面预算

- 多维预算模型（组织/产品/渠道/期间/版本）
- 业务驱动因子 × 单价/费率 → 自动推导财务预算
- 版本管理与滚动预测
- 预实对比与差异分析

### 3.3 M3 管理分析

- 费用分摊规则（收入/人数等权重）
- KPI 引擎（合计/比率）
- 管理报表结构化输出
- （路线图）仪表盘订阅、Office 导出

### 3.4 M0 平台

- 示例数据一键重置
- REST API
- VitePress 文档站
- 纯 TS 领域引擎（可单测、可嵌入）

## 4. 技术方案摘要

```text
packages/core   纯函数领域引擎（无 IO）→ 单测友好
packages/schema 共享类型契约
apps/api        Fastify REST + JSON 持久化（可换 PG）
apps/web        React 工作台
docs            VitePress
```

**为何这样切**：引擎与界面解耦，未来可 CLI 化、可嵌入其他系统、可换存储。

## 5. 差异化创意

1. **合并「阶段流水线」可视化**：每一步的金额变化可展开，降低审计沟通成本。  
2. **预算公式与驱动同屏**：业务同事看得懂「销量×单价=收入预算」。  
3. **教学 Demo 集团「华衡集团」**：内置 HKD 子公司 + 内部往来，开箱就能演示 FX 与抵消。  
4. **Apache-2.0 社区友好**：无双许可陷阱，可私有化。  
5. **文档即产品**：方案、架构、引擎说明与代码同仓演进。

## 6. 开源与合规边界

- 功能对标行业通用 EPM 能力域，**不**复制任何商业产品品牌、界面、文案或源码。  
- 会计处理以适用准则（如 CAS/IFRS）与企业自身政策为准，软件提供可配置引擎而非会计意见。  
- 贡献者签署 DCO；代码 Apache-2.0；文档可 CC-BY-4.0（可选）。

## 7. 商业化路径（社区项目可选）

| 阶段 | 模式 |
|------|------|
| 社区 | 免费核心引擎 + 文档 |
| 增强 | 私有化部署包、连接器（用友/金蝶/SAP）、SSO、等保加固 |
| 服务 | 实施方法论、培训认证、行业模板 |
| 云 | 多租户 SaaS（后期） |

## 8. 成功指标

- 引擎单测覆盖合并/预算/分摊主路径  
- 10 分钟内完成「安装→seed→打开工作台看到合并结果」  
- 外部贡献者可通过 docs 独立理解数据模型并提 PR  
- 示例集团演示：FX + 抵消 + 预实差异一次讲清  

## 9. 与调研结论的映射

| 对标能力域 | Stratus 落点 |

| 万表同源分析 | 统一 fact 模型 + KPI/分摊 |
| 产品+文档 | api/web/docs 同仓 |
