# 开源治理

## 许可

本仓库代码以 **Apache License 2.0** 发布，见根目录 [`LICENSE`](https://github.com/stratus-epm/stratus-epm/blob/main/LICENSE)。

## 贡献

1. Fork 与特性分支  
2. 保持 `pnpm test` 通过  
3. 引擎行为变更同步更新 `docs/guide/`  
4. PR 描述写清：场景、数据模型影响、测试证据  
5. 提交信息使用祈使句（英文或中文均可）  

## 行为准则

尊重不同背景的贡献者；技术争论对事不对人；禁止骚扰。

## 安全披露

请勿在公开 Issue 中粘贴敏感生产数据。安全问题通过私密渠道联系维护者。

## 商标

「Stratus EPM / 层云」为项目名称；贡献者保留各自版权，统一按 Apache-2.0 授权使用。

## 免责声明

本软件按「现状」提供，不构成会计、审计或法律意见。合并结果的合规性由使用方结合适用准则与专业判断负责。
