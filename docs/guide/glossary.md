# 术语表

| 术语 | 解释 |
|------|------|
| EPM | Enterprise Performance Management，企业绩效管理 |
| 合并报表 | 将集团内多个主体财务报表汇总抵消后的集团报表 |
| Trading Partner | 关联方维度，用于内部交易匹配 |
| 持股比例 ownershipPct | 母公司对子公司的持股 |
| 折算 translation | 外币报表按汇率换算为集团币 |
| 抵消 elimination | 去除内部交易对集团报表的影响 |
| 驱动因子 driver | 业务量、人数等预算推导输入 |
| 万表同源 | 多类报表共用同一套治理后的数据 |
