# 42 · 移动端看板

本章属于 Stratus EPM 开发手册，聚焦「**移动端看板**」。

## 目标

在开源合并/预算/分析平台中，将「移动端看板」拆解为可实现、可测试、可交付的工程任务。

## 设计要点

1. 明确业务输入与输出（科目、组织、期间、维度）。
2. 在 `packages/core` 中保持纯函数，便于单测与复用。
3. 将规则配置化，避免硬编码集团差异。
4. 为演示集团「华衡集团」提供可观察的样例结果。

## 与引擎的关系

- 合并流水线阶段若涉及本主题，应在 `runConsolidation` 的对应步骤扩展。
- 预算/分摊相关则扩展 `runBudget` / `runAllocation`。
- 所有行为变更同步更新 `docs/guide` 与测试。
